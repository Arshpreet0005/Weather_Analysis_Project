WEATHER DATA ANALYSIS AND RAINFALL PREDICTION

========================================
PROJECT DESCRIPTION
===================

This project performs Exploratory Data Analysis (EDA) and Machine Learning on weather data to analyze weather patterns and predict rainfall.

The project includes:

1. Missing Value Analysis
2. Correlation Analysis
3. Rainfall Distribution Analysis
4. Rain Today / Rain Tomorrow Analysis
5. Humidity vs Rainfall Analysis
6. Outlier Detection
7. Linear Regression Model
8. Decision Tree Regressor
9. Random Forest Regressor
10. Feature Importance Analysis
11. Model Performance Comparison
12. Actual vs Predicted Visualization

========================================
PROJECT REQUIREMENTS
====================

Python Version:
Python 3.9 or above

Required Libraries:

* pandas
* numpy
* matplotlib
* seaborn
* scikit-learn

Install dependencies using:

pip install -r requirements.txt

HOW TO RUN THE PROJECT
======================

Step 1:
Open terminal in the project folder.

Step 2:
Install required libraries.

Command:

pip install -r requirements.txt

Step 3:
Run the Python script.

Command:

python weather_analysis.py
